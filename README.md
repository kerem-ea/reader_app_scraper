# Reader App Scraper

A complete system for scraping novel chapters from FreeWebNovel, converting scraped data into standardized EPUB books, and reading them locally in a dedicated desktop application.

## Workflow

1. Clone or download the repository from GitHub.

2. Create a virtual environment and install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Scrape novel chapters:

```powershell
cd scraper
python scrape.py
```

Follow the interactive prompts to choose your novel slug and chapter range. Scraped raw data and cover image are saved to `data/<novel-slug>/`.

4. Convert scraped JSON to EPUB format:

```powershell
cd ..
python epub.py
```

Run `epub.py` after scraping. An interactive menu will list all scraped novels in `data/`. Select the novel to convert its raw JSON into a standardized `.epub` book file.

5. Run the Reader Application:

- Run via Python:

```powershell
cd reading_app
python app.py
```

- Or build and run the standalone Windows executable:

```powershell
.\build.bat
.\reader.exe
```

The reader application discovers `.epub` files under `data/` (or `scraper/data/`) generated by `epub.py`. It tracks reading progress per novel in `last_read.json`.
