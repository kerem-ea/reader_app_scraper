# Reader App Scraper

A complete system for scraping novel chapters from FreeWebNovel, converting scraped data into standardized EPUB books, and reading them locally in a dedicated desktop application.

## Workflow

1. Clone or download the repository from GitHub.

2. Create a virtual environment and install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Scrape novel chapters:

```powershell
cd scraper
python scrape.py
```

Follow the interactive prompts to choose your novel slug and chapter range. Scraped raw data is saved to `data/<novel-slug>/<novel-slug>_chapters_raw.json`.

4. Convert scraped JSON to EPUB format:

```powershell
cd ..
python epub.py
```

You **must** run `epub.py` after scraping. An interactive menu will list all scraped novels in `data/`. Select the novel to convert its raw JSON into a standardized `.epub` book file.

5. Run the Reader Application:

- Run via Python:

```powershell
cd reading_app
python app.py
```

- Or build and run the standalone Windows executable:

```powershell
.\build.bat
.\reader.exe
```

The reader application discovers `.epub` files under `data/` (or `scraper/data/`) generated by `epub.py`. The application does **not** read raw `*_chapters_raw.json` files directly—it reads the converted `.epub` books.

## Project Structure

```
reader_app_scraper/
├── data/             Root data directory for scraped raw JSON and generated EPUBs
├── scraper/          Novel scraper component
│   ├── scrape.py     Main interactive scraper entry point
│   ├── debug_chapter.py Debug tool for fetching single chapters
│   └── ...
├── epub.py           Interactive EPUB generator script (converts JSON data to EPUB files)
├── reading_app/      Desktop reader application
│   ├── app.py        Flask backend and EPUB parser engine
│   ├── reader.spec   PyInstaller build configuration
│   ├── static/       Frontend assets
│   └── templates/    HTML templates
├── build.bat         Windows build script
└── requirements.txt  Project dependencies
```
